# PRD · Yuze-agent 产品需求文档

| 项 | 内容 |
|---|---|
| 产品名称 | Yuze-agent（Chrome 侧边栏 AI Agent） |
| 作者 | Yuze（Hickey-Yuze） |
| 版本 | 0.4.0 |
| 文档状态 | 已实现并交付（对应仓库 main 分支） |
| 更新日期 | 2025-10 |

---

## 1. 背景与问题

用户日常在浏览器内处理大量信息（阅读、分析表格、整理页面、生成文档），现有 AI 侧边栏产品（Yuze 等）要么收费、要么闭源、要么无法本地化模型与扩展工具链。需要一款：

- 完全跑在 Chrome 扩展内、不依赖原生二进制 / Playwright；
- 可接入任意 OpenAI 兼容模型（含本机网关，数据不出本机）；
- 能像通用 agent 一样调工具完成任务（页面操控、MCP、文件生成）；
- 交互对标 Yuze（macOS 视觉、流式思考、引用、技炉）。

## 2. 产品定位

**一句话**：浏览器侧边栏里的本地优先 AI agent。

**目标用户**：需要浏览器内自动化与文档产出的开发者 / 效率用户。

**核心价值**：自然语言 → 工具调用 → 结果落盘，全程本机可控。

## 3. 目标（本阶段）

1. 对话体验对标 Yuze：流式思考、无闪烁渲染、macOS 风格 UI。
2. 任务执行可靠：工具循环按进展自动收敛，不死循环、不空转。
3. 能力可扩展：MCP 多服务器可视化配置；技炉（技能脚本）可安装、可自动运行。
4. 产出可交付：PDF/PPT/Excel/Word/图片/代码文件生成并卡片化下载。

## 4. 功能需求

### 4.1 对话（P0）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| F-01 | 问答 / 任务双模式 | 问答不携带 tools；任务模式启用工具循环 |
| F-02 | 流式输出（SSE） | `delta.content` / `delta.reasoning_content` 逐块渲染；工具调用按 index 流式合并 |
| F-03 | 思考过程区块 | 顶部「思考过程」+ 折叠 chevron，完成自动折叠；流式期间不重建 DOM（`updateLive` 只改最后一条） |
| F-04 | 停止 | 生成中发送键变停止键，中断请求与循环 |
| F-05 | 循环治理 | 上限 300 轮兜底；连续多轮同签名且无新内容即停止并提示 |

### 4.2 页面操控与上下文（P0）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| F-06 | 浏览器工具集 | snapshot / click / type / navigate / get_text / evaluate / screenshot 等，经 `chrome.debugger` CDP |
| F-07 | 引用 | `@` 菜单：打开的标签页（读选区或正文）、收藏、本地文件、文件夹；chip 可移除 |
| F-08 | 自动引用 | 开关开启后引用条随 `tabs.onActivated` / `onUpdated` 更新为当前页；可取消单条 |
| F-09 | 截图 | `Page.captureScreenshot`，作为引用随消息发送（多模态） |

### 4.3 技炉（P0）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| F-10 | 技炉库 | 内置 33 个（名称/描述/作者/安装数原样保留），搜索与分类筛选，详情页完整信息 |
| F-11 | 脚本运行 | 手动：`chrome.scripting.executeScript` 注入当前标签页；自动：`background.js` 监听 `tabs.onUpdated` 按「适用网站」前缀匹配注入 |
| F-12 | 适用网站 | 详情页可编辑（`skillSites[id]`），留空 = 全部网站 |
| F-13 | 任务 chip | 点技炉或任务项只生成可移除粉色 chip，不写入输入框 |

### 4.4 MCP（P0）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| F-14 | 配置面板 | 列表（全部/推荐/自定义 Tab）+ 新增/编辑弹窗（表单 / JSON 导入、Headers 可增删）+ 测试连接 + 删除 |
| F-15 | 连接 | Streamable HTTP JSON-RPC；兼容 `application/json` 与 SSE 两种响应；Header 支持鉴权 |
| F-16 | 工具挂载 | `tools/list` 自动拉取，命名 `mcp_<slug>`（冲突加序号），并入任务模式工具表 |

### 4.5 文件生成（P0）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| F-17 | filegen MCP | PDF（headless Chrome printToPDF，回退 pdf-lib）/ PPTX / XLSX / DOCX / 图片 / `save_js` |
| F-18 | 产物卡片 | 文件名/大小/图标 + 打开/文件夹/复制路径/另存为/加入对话框 |
| F-19 | 强约束 | 任务模式系统提示强制文档类产出必须调 `mcp_gen_*`，缺失时明确说明并停止 |

### 4.6 设置与提供商（P1）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| F-20 | 设置弹窗 | macOS 卡片式：提供商列表（状态点/本机徽标/编辑）+ 添加 + 技炉/MCP 分组行 + 保存并验证 |
| F-21 | 多提供商 | OpenAI 兼容任意 endpoint；「获取模型」拉取 `/v1/models`；切换即时生效 |
| F-22 | 会话 | 按当前页面分组抽屉 + 全部对话；删除会话；标题与正文全文搜索 |

## 5. 非功能需求

- **视觉**：macOS 风格（`#f5f5f7` 灰阶 + `#007aff` 系统蓝 + SF 字体 + 毛玻璃顶栏）；不引入其他主色。
- **性能**：流式渲染禁止全量重建 DOM；会话 300ms 防抖落盘。
- **隐私**：API Key、会话数据仅存 `chrome.storage.local`，不上传第三方。
- **安全**：调试器仅按需 attach/detach；脚本注入目标由用户配置的适用网站决定。
- **兼容**：Chrome ≥ 116（MV3 sidePanel API）。

## 6. 范围外（Non-goals）

- 不自托管模型、不做模型推理。
- 不做 Chrome Web Store 分发打包（当前为开发者模式加载）。
- 自定义技炉的编辑 / 上传文件 / 对话创建为后续迭代。

## 8. 风险与已知问题

- 静态权限变更需扩展开关重开；刷新扩展后旧侧边栏不更新（见 README「安装」注意事项）。
- 受保护页面（`chrome://`、Web Store）无法附加调试器。
- 截图多模态消息要求模型支持视觉。
- 技炉脚本依赖原站结构（如 b15 依赖 `p0.meituan.net` 图片），原站改版会失效。
